# ✊ Rock Paper Scissors

A beginner-friendly Python command-line game where you play **Rock, Paper, Scissors** against the computer.

## 🧰 Built With
- Python
- `random` module

## ▶️ Run the Game

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder and run:

```bash
python First_project.py
```

## 🎮 How to Play
When prompted, enter:
- `0` for Rock
- `1` for Paper
- `2` for Scissors

The computer randomly selects a move and the program displays both choices and a result.

## 📚 What This Project Practices
- Variables and user input
- Dictionaries
- Random choices
- Conditional logic
